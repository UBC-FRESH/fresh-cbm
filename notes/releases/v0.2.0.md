# fresh-cbm v0.2.0

Package release for the exact libcbm stand-state cache.

## Highlights

- content-addressed cache client and JSON-Schema manifest validation
- chain-family contract and legacy manifest support
- reusable `fresh_cbm.effects` block/fragment projection
- `fresh-cbm-build`, `fresh-cbm-validate`, `fresh-cbm-package`,
  `fresh-cbm-bench`, and `fresh-cbm-verify`
- wheel/sdist install smoke tests in CI
- published TSA41 and TSA08 caches

## Install

```bash
pip install dist/fresh_cbm-0.2.0-py3-none-any.whl
```

## Verification

```bash
fresh-cbm-verify --cache /path/to/cache
```

## PyPI

Not published to PyPI as part of P5. The GitHub release is the distribution
channel; PyPI publication needs a separate maintainer decision and credentials.
