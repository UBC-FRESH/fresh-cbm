the UBC-FRESH dev workflow; the validator is ``scripts/check_workflow.py`` and
the dashboard is ``scripts/dashboard.py``.

Read before changing anything:

- ``AGENTS.md``
- ``ROADMAP.md``
- ``CHANGE_LOG.md``
- the guide or reference page for the task
